# Mechanism and reviewer audit

Boundary: applications choose the immutable comparison task and full inventory.
Sources publish actual report bytes. GenLayer independently acquires those bytes
and semantically maps ALL measurements to objectives/context. Numeric source
ranges and those consensus labels drive hulls and robust dominance envelopes.

| Objection | Implemented mechanism |
|---|---|
| Graph/name variant | No objects, edges, mutable head, parent versions or owner mutation. Write-once independent source slots plus barrier finalization |
| Decorative AI | Misclassifying A's one-worker latency row changes its hull and whether C is certainly non-dominated; mapping meaning/scope is consequential |
| URL stored but not fetched | Each validator fetches the entire pinned response, checks raw bytes/status/hash/schema and uses the actual notes/row contents |
| Self-reported confidence or outcome | Caller supplies no matrix, ranges, scores, confidence or frontier; model cannot invent numeric output |
| Select favorable evidence | All alternative slots are mandatory; all row/objective cells are classified; every MATCH enters the hull |
| Uncertainty approved | Missing/ambiguous metric stays nonnegative-unbounded; possible and certain membership are separate; failed source makes whole result HELD |
| Threshold-crossing tolerance | Exact complete-report equality, no numeric tolerance and no score threshold |
| Cross-stream/case substitution | Source index, panel, deployment and immutable input root are checked before and after consensus |
| Stale/repeated use | Observations and result cannot overwrite; native creator nonce is unique; consumer binds exact input root |

At most 4 alternatives, 3 objectives, 4 measurement rows per source; each full
report <=6000 bytes. Source scope interpretation is the GenLayer operation. Hulls,
bit-mask barriers and dominance are deliberately deterministic safety/accounting.

Certain/possible frontiers follow from independent Cartesian ranges, not an AI
claim of optimality. Each excluded candidate has an explicit certain dominator.
An exhaustive grid-completion test checks the solver against a different method.
An independent Node checker enumerates endpoint completions rather than trusting
the contract's best/worst pairwise comparisons.

This is one representative trade-off mechanism. It is not a parallel domain
variant of the coalition attribution, graph mutation, set cover, ranking,
prediction scoring or sequential annotation audit submissions.
